# aoblog

A build journal by [Andre Ortiz](https://andreortiz.com) — documenting the
process of designing a design system, a brand, and products with AI, plus a
side channel of AI-assisted short fiction ("Shorts").

Built with [Astro](https://astro.build), Tailwind CSS v4, and MDX.

## Commands

```bash
npm install
npm run dev       # dev server → http://localhost:4321
npm run build     # production build → ./dist
npm run preview   # preview the dist build
```

See [PLAN.md](PLAN.md) for the build plan and progress log.
